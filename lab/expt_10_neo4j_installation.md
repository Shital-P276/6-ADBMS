# Expt 10: Installation of Neo4j NoSQL Database

## Objective
Install Neo4j and verify database access.

## Software
- Neo4j Community/Enterprise
- Neo4j Browser / Cypher Shell

## Basic Steps
1. Install Neo4j.
2. Start service (`neo4j start` or via Desktop).
3. Open Neo4j Browser (`http://localhost:7474`).
4. Login and set password.

## Verification (Cypher)
```cypher
RETURN 1 AS status;
```
